LIKKsyco

A personal page for networking and distributed computing.

On this course

The page is reached by a name, an address, and a transport connection. DNS turns the name into an IP address. TCP carries the HTTP response. The files themselves are static: this document, a style sheet, and a short script.

What the modules of work are

  • Socket streams, TCP and UDP
  • This site, and the path packets take to it
  • Map, shuffle, and reduce
  • The same word count in Hadoop and Spark
  • A Spark MLlib model on the gesture files

How this page is fetched

  1. The resolver looks up likksyco.github.io.
  2. TCP opens a connection to port 443.
  3. TLS protects the HTTP request for these three files.
